# Deployment Guide for Dobrix Rechner

## Prerequisites
- MongoDB Atlas database (already configured)
- Node.js hosting (see options below)
- Domain: rechner.dobrix.org

---

## Option 1: Deploy to Vercel (RECOMMENDED - Easiest)

### Steps:
1. **Create `.env.production` file:**
   ```env
   MONGODB_URI=
   ```

2. **Push code to GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin YOUR_GITHUB_REPO_URL
   git push -u origin main
   ```

3. **Deploy on Vercel:**
   - Go to [vercel.com](https://vercel.com)
   - Sign in with GitHub
   - Click "New Project"
   - Import your repository
   - Add Environment Variable: `MONGODB_URI`
   - Click "Deploy"

4. **Add Custom Domain:**
   - In Vercel dashboard → Settings → Domains
   - Add `rechner.dobrix.org`
   - Follow DNS instructions (add CNAME record in SiteGround)

---

## Option 2: Deploy to Railway.app

### Steps:
1. **Create account at [railway.app](https://railway.app)**

2. **Create `.env.production`** (same as above)

3. **Deploy:**
   ```bash
   npm install -g @railway/cli
   railway login
   railway init
   railway up
   ```

4. **Add environment variable in Railway dashboard:**
   - MONGODB_URI

5. **Configure custom domain:**
   - Settings → Generate Domain
   - Add CNAME in SiteGround DNS: `rechner.dobrix.org` → `your-app.railway.app`

---

## Option 3: Deploy to SiteGround (If Node.js is supported)

### Check if your plan supports Node.js:
1. Log into SiteGround cPanel
2. Look for "Node.js" or "Application Manager"
3. If available, continue below

### Build and Deploy Steps:

1. **Build the app locally:**
   ```bash
   npm run build
   ```

2. **Files to upload via FTP/SFTP:**
   - `.next/` folder (generated by build)
   - `public/` folder
   - `package.json`
   - `package-lock.json`
   - `next.config.ts`

3. **Create `.env.production` on server:**
   ```env
   MONGODB_URI=******
   NODE_ENV=production
   ```

4. **Via SSH on SiteGround:**
   ```bash
   cd /path/to/your/app
   npm install --production
   npm run start
   ```

5. **Keep server running (use PM2):**
   ```bash
   npm install -g pm2
   pm2 start npm --name "dobrix-rechner" -- start
   pm2 save
   pm2 startup
   ```

6. **Configure Apache/Nginx proxy in cPanel**
   - Point `rechner.dobrix.org` to `localhost:3000`

## Important: Update MongoDB Connection

For production, ensure MongoDB Atlas allows connections from:
1. Go to MongoDB Atlas → Network Access
2. Add IP: `0.0.0.0/0` (allow from anywhere) OR
3. Add specific IPs from your hosting provider

## Testing After Deployment

1. Visit `https://rechner.dobrix.org`
2. Test login functionality
3. Test creating abrechnungen
4. Check if all API routes work

---

## Troubleshooting

### If pages don't load:
- Check server logs
- Verify environment variables are set
- Ensure MongoDB connection string is correct

### If API routes fail:
- Check MongoDB Atlas network access
- Verify API routes are built correctly
- Check server logs for errors

### If custom domain doesn't work:
- DNS propagation can take 24-48 hours
- Verify CNAME record is correct in SiteGround DNS
